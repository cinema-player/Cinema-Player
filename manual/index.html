Cinema Player operator manual Cinema Player Bedienungsanleitung

Cinema Player plays a cinema program on a dedicated projector output while the projectionist works on a separate control screen. The big screen shows only the picture — never menus, clocks, or subtitles unless you choose a subtitle track.

Cinema Player spielt ein Kinoprogramm auf einem eigenen Beamerausgang, während die Vorführung an einem separaten Kontrollbildschirm bedient wird. Die große Leinwand zeigt nur das Bild — keine Menüs, Uhren oder Untertitel, außer Sie wählen eine Untertitelspur.

1. Start and screens 1. Start und Bildschirme

Connect two outputs from the graphics card: one for the control monitor, one for the projector (HDMI, DVI, or DisplayPort). From the project folder run ./start or pixi run start. The desktop file Cinema-Player.desktop starts the same script.

Schließen Sie zwei Ausgänge der Grafikkarte an: einen für den Kontrollmonitor, einen für den Beamer (HDMI, DVI oder DisplayPort). Im Projektordner starten Sie mit ./start oder pixi run start. Die Datei Cinema-Player.desktop startet dasselbe Skript.

If only one display is found, a warning asks you to attach a second output and select it under Beamer output. The projector instance of mpv uses that connector. Preview audio can stay on the control machine; program audio goes out with the projector HDMI.

Wird nur ein Bildschirm gefunden, warnt Cinema Player und bittet, einen zweiten Ausgang anzuschließen und unter Beamerausgang zu wählen. Die mpv-Instanz für den Beamer nutzt diesen Anschluss. Vorschau-Ton kann am Kontrollrechner bleiben; der Programmton geht mit dem HDMI des Beamers.

2. Control window 2. Kontrollfenster

The header shows the logo, the version, X11 or Wayland, and the settings menu (three lines, top right). Below that the window is split: program and playlist on the left, beamer and preview on the right.

Die Kopfzeile zeigt das Logo, die Version, X11 oder Wayland und das Einstellungsmenü (drei Striche oben rechts). Darunter ist das Fenster geteilt: Programm und Playlist links, Beamer und Vorschau rechts.

  • Status bar — program state, clip name, playlist position.
  • Statuszeile — Programmzustand, Clipname, Position in der Playlist.
  • Program block — progress, volume (and stored A/V delay if one exists), In/Out, transport, four clocks, VU meter.
  • Programmblock — Verlauf, Lautstärke (und gespeicherter A/V-Versatz, falls vorhanden), In/Out, Transport, vier Uhren, VU-Meter.
  • Playlist tools — name, import / new / load / save, beamer change, autoplay delay, idle media.
  • Playlist-Werkzeuge — Name, Import / Neu / Laden / Speichern, Beamerwechsel, Autoplay-Pause, Pausenmedium.
  • Playlist — the running order.
  • Playlist — die Spielfolge.
  • Beamer status — aspect ratio, available rates and resolutions, OK or Mismatch.
  • Beamer-Status — Seitenverhältnis, verfügbare Frequenzen und Auflösungen, OK oder Abweichung.
  • Preview — Live/Preview badge, metadata, clip settings, picture, meters, transport, In/Out.
  • Vorschau — Live/Vorschau, Metadaten, Clip-Einstellungen, Bild, Meter, Transport, In/Out.

Fullscreen on the control monitor: F11 or Settings → Fullscreen. It never covers the projector output.

Vollbild auf dem Kontrollmonitor: F11 oder Einstellungen → Vollbildmodus. Der Beamerausgang wird davon nicht überdeckt.

3. Settings 3. Einstellungen

Open the burger menu at the top right of the header.

Öffnen Sie das Burger-Menü oben rechts in der Kopfzeile.

  • Media directories — add one or more folders. They are saved and offered when media is imported into the playlist. The import dialog can also Copy files into a chosen folder and link those copies. A popup shows the copy progress.
  • Medienverzeichnisse — einen oder mehrere Ordner hinzufügen. Sie werden gespeichert und beim Laden von Medien in die Playlist angeboten. Im Import-Dialog können Dateien mit Files kopieren in einen gewählten Ordner kopiert und von dort verlinkt werden. Ein Popup zeigt den Kopierfortschritt.
  • Remote control — LAN API for a smartphone (default port 8765). A token is required. A radio icon in the header shows when it is running. Resume, Pause, Still, Stop (clip only, not the program), volume, playlist, progress, and clocks. Tap a playlist row to set the program pointer. Pause, Still, Stop, and the program pointer must be confirmed on the phone.
  • Fernsteuerung — LAN-API fürs Smartphone (Standardport 8765). Ein Token ist Pflicht. Ein Funk-Icon in der Kopfzeile zeigt, wenn sie läuft. Weiter, Pause, Standbild, Stop (nur Clip, nicht das Programm), Lautstärke, Playlist, Fortschritt und Zeiten. Antippen einer Playlistzeile setzt den Programmzeiger. Pause, Standbild, Stop und der Programmzeiger müssen am Telefon bestätigt werden.
  • Fullscreen — control monitor only (F11).
  • Vollbildmodus — nur Kontrollmonitor (F11).
  • Light / dark design — colours of the control window.
  • Helles / dunkles Design — Farben des Kontrollfensters.
  • Language — English or Deutsch. The brand name Cinema Player stays untranslated.
  • Sprache — English oder Deutsch. Der Name Cinema Player bleibt unübersetzt.
  • Beamer output — which connector is the projector. Locked while PLAYING. The submenu also has EDID, which opens a window with the projector’s complete EDID.
  • Beamerausgang — welcher Anschluss der Beamer ist. Während WIEDERGABE gesperrt. Im Untermenü gibt es außerdem EDID: ein Fenster mit den vollständigen EDID-Daten des Beamers.
  • Use default Idle Media — checkbox. When on, the projector idle clip is the file in idle. The choice is saved and applied again at the next start.
  • Standard-Pausenmedium verwenden — Kontrollkästchen. Wenn aktiv, ist das Pausenmedium die Datei im Ordner idle. Die Wahl wird gespeichert und beim nächsten Start wieder angewendet.
  • Calibration — in OFF and while already calibrating. Beamer test image (logo on the projector until you close the dialog; only in OFF). Video and Audio each have a submenu: Load all files (every clip in testdata/videotestdata or testdata/audiosyncdata, loop on), then any .pls playlists in that folder. Audio also has the A/V delay slider.
  • Kalibrierung — bei AUS und während einer Kalibrierung. Beamer-Testbild (Logo auf dem Beamer, bis der Dialog geschlossen wird; nur bei AUS). Video und Audio haben je ein Untermenü: Alle Files laden (alle Clips in testdata/videotestdata bzw. testdata/audiosyncdata, Loop an), darunter vorhandene .pls-Playlists. Audio hat zusätzlich den A/V-Versatzregler.
  • Quit — only enabled in OFF.
  • Beenden — nur bei AUS aktiv.

4. Program states and transport 4. Programmzustände und Transport

A show has three states. Start only arms the program. Resume rolls the clip. Idle media (if set) appears only in PROGRAM, never in OFF. Video calibration and Audio calibration overlay that status; Stop from PROGRAM leaves the mode.

Eine Vorstellung hat drei Zustände. Start schaltet das Programm nur scharf. Weiter startet den Clip. Ein Pausenmedium erscheint nur im Zustand PROGRAMM, niemals bei AUS. Videokalibrierung und Audiokalibrierung überlagern diesen Status; Stop aus PROGRAMM verlässt den Modus.

Button Taste Action Wirkung
Start Start OFF → PROGRAM. Does not start the file. AUS → PROGRAMM. Startet die Datei nicht.
Resume Weiter Roll the current clip, unpause, or leave still. Disabled while the clip is rolling. Aktuellen Clip starten, Pause aufheben oder Standbild verlassen. Während der Clip läuft inaktiv.
Pause Pause Hold position; projector goes black. Confirm first. Position halten; Beamer wird schwarz. Zuerst bestätigen.
Still Standbild Freeze the current frame on the projector. Confirm first. Aktuelles Bild auf dem Beamer einfrieren. Zuerst bestätigen.
Stop Stop While PLAYING: end the clip → PROGRAM. Again: end the program → OFF. In calibration, Stop from PROGRAM leaves the mode. Bei WIEDERGABE: Clip beenden → PROGRAMM. Nochmals: Programm beenden → AUS. In der Kalibrierung verlässt Stop aus PROGRAMM den Modus.

Buttons that cannot be used are shown with a disabled icon (grey) and an arrow cursor. Pause and Still only work while PLAYING. Resume is dead while the clip is rolling. Stop is dead in OFF.

Tasten, die nicht gelten, erscheinen als graues Disabled-Symbol mit Pfeilcursor. Pause und Standbild nur bei WIEDERGABE. Weiter ist tot, solange der Clip läuft. Stop ist bei AUS tot.

The four clocks are Total, Elapsed, Remaining, and End (wall-clock time when the clip will finish).

Die vier Uhren sind Gesamt, Gelaufen, Rest und Ende (Uhrzeit, zu der der Clip endet).

Autoplay on a clip starts the next file after the autoplay delay (black). Idle media is not shown in that gap. After the last clip the program stays in PROGRAM until you Stop.

Autoplay an einem Clip startet die nächste Datei nach der Autoplay-Pause (schwarz). In dieser Lücke erscheint kein Pausenmedium. Nach dem letzten Clip bleibt das Programm auf PROGRAMM, bis Sie Stoppen.

6. Preview and In/Out 6. Vorschau und In/Out

Click a playlist row to load it in preview (yellow Preview). Click the badge to follow the program output (Live) when a clip is on air. In/Out cannot be edited while that clip is on air.

Ein Klick auf eine Playlist-Zeile lädt sie in die Vorschau (gelb Vorschau). Ein Klick auf das Abzeichen folgt der Programmausgabe (Live), wenn ein Clip läuft. In/Out lassen sich nicht ändern, solange dieser Clip auf Sendung ist.

Per clip you can set autoplay, loop (videos; ended with Resume), played, audio track, and subtitle track (off unless you pick one). Program playback uses the In and Out marks. The program progress bar and clocks always follow those marks, even if idle media is looping on the projector.

Pro Clip lassen sich Autoplay, Loop (Videos; endet mit Weiter), Gespielt, Tonspur und Untertitel (aus, bis eine Spur gewählt wird) setzen. Die Programmwiedergabe nutzt die In- und Out-Marken. Verlauf und Uhren im Programm folgen immer diesen Marken, auch wenn auf dem Beamer ein Pausenmedium läuft.

7. Beamer 7. Beamer

The first line is the projector’s name from its EDID (the same identity as under Settings → Beamer output → EDID). Then the panel lists every refresh rate and every resolution the projector currently advertises. The mode that is on the projector now is drawn larger and bolder in that list. Values that belong to the program pointer are blue; values that belong to a clip selected for preview are yellow (the preview yellow of the playlist). A 30 fps clip marks 60p when 60 Hz is in the list (twice the frame rate). Extra entries appear in blue or yellow only when the clip’s frame rate or resolution is not among the advertised modes.

Die erste Zeile ist der Gerätename aus der EDID des Beamers (dieselbe Identität wie unter Einstellungen → Beamerausgang → EDID). Danach listet das Feld jede Frequenz und jede Auflösung, die der Beamer derzeit meldet. Der Modus, der gerade auf dem Beamer liegt, steht in dieser Liste größer und fett. Werte des Programmzeigers sind blau; Werte eines für die Vorschau gewählten Clips sind gelb (das Gelb der Playlist). Ein 30-fps-Clip markiert 60p, wenn 60 Hz in der Liste steht (zweifache Bildrate). Zusätzliche Einträge erscheinen nur blau oder gelb, wenn Bildrate oder Auflösung des Clips nicht unter den gemeldeten Modi sind.

OK / Mismatch compares the clip with the capability list, not with the rate that happens to be active. If 60 Hz is listed, 30 fps is OK even while the projector is still at 50 Hz. Before a clip rolls, Cinema Player switches to a mode at the video resolution whose refresh matches the frame rate or an integer multiple. If the projector has no such mode, a custom xrandr mode can be created at playback time on X11. GNOME Wayland can only use modes the display already advertises. Import and probe never create modes.

OK / Abweichung vergleicht den Clip mit der Fähigkeitsliste, nicht mit der gerade aktiven Frequenz. Steht 60 Hz in der Liste, ist 30 fps OK, auch wenn der Beamer noch auf 50 Hz liegt. Bevor ein Clip läuft, schaltet Cinema Player auf einen Modus in der Videoauflösung, dessen Frequenz zur Bildrate oder einem ganzzahligen Vielfachen passt. Fehlt ein solcher Modus, kann unter X11 zur Wiedergabe ein eigener xrandr-Modus erzeugt werden. Unter GNOME Wayland stehen nur die vom Gerät gemeldeten Modi zur Verfügung. Import und Analyse erzeugen keine Modi.

8. Volume and loudness 8. Lautstärke und Lautheit

Each clip has its own volume. Adjust it in preview and press Save volume. The program fader follows the clip that is on air. Program and preview each have a VU meter (separate audio filters).

Jeder Clip hat eine eigene Lautstärke. Stellen Sie sie in der Vorschau und drücken Sie Lautstärke speichern. Der Programmregler folgt dem Clip auf Sendung. Programm und Vorschau haben je ein VU-Meter (getrennte Audiofilter).

Analyze loudness (playlist menu, only in OFF) runs ffmpeg EBU R128 on every video. Integrated LUFS is stored on the entry and shown in the playlist row and above the preview meter. This can take a while.

Lautheit analysieren (Playlist-Menü, nur bei AUS) misst mit ffmpeg EBU R128 jedes Video. Die integrierte LUFS-Zahl steht in der Playlist-Zeile und über dem Vorschaumeter. Das kann dauern.

9. Still images 9. Standbilder

Images can sit in the playlist. Set a display time in seconds. After that time the program stops or autoplays the next item. Display time 0 keeps the still until Resume. Preview transport is hidden for stills. If a still is followed by a video, the output refresh is set to the video frame rate first, so the projector does not renegotiate when the video starts.

Bilder können in der Playlist stehen. Die Anzeigezeit in Sekunden festlegen. Danach stoppt das Programm oder startet den nächsten Eintrag per Autoplay. Anzeigezeit 0 hält das Bild bis Weiter. Der Vorschau-Transport ist bei Standbildern ausgeblendet. Folgt auf ein Bild ein Video, wird die Ausgangsfrequenz zuerst auf die Videobildrate gesetzt, damit der Beamer beim Videostart nicht neu verhandelt.

10. Quit 10. Beenden

Quit, the window close box, and Ctrl+F4 only work in OFF. If the program is armed or playing, Cinema Player asks you to Stop first so the booth cannot drop a live show by closing the window.

Beenden, das Schließen des Fensters und Strg+F4 gelten nur bei AUS. Ist das Programm scharf oder in Wiedergabe, verlangt Cinema Player zuerst Stop — damit die Vorstellung nicht durch Schließen des Fensters abbricht.
