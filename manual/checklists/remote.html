Cinema Player

Fernsteuerung Remote control

Vorderseite · Grundfunktionen Front · Basic steps

  1. Einschalten. Funk-Icon rechts oben. Die API im Fenster einschalten. Das Icon wird grün. Switch on. Radio icon at the top right. Turn the API on in that window. The icon turns green.

  2. WLAN. Telefon und Pult im selben Netz. WLAN. Phone and booth on the same network.

  3. Verbinden. QR-Code scannen. Sonst die angezeigte Adresse in den Browser und denselben Token eintragen. Connect. Scan the QR code. If that fails, open the shown address and enter the same token.

  4. Transport. Start schaltet scharf, Weiter startet den Film. Stop, Pause und Still fragen wie am Pult. Transport. Start arms the show, Resume starts the film. Stop, Pause, and Still ask the same questions as the booth.

  5. Uhren. Rest und Ende sind die großen Zeiten. Clocks. Remaining and End are the large times.

  6. Playlist. Eine Zeile antippen setzt den Programmzeiger. Während der Wiedergabe ist das gesperrt und muss bestätigt werden. Playlist. Tap a row to set the program pointer. During playback it is locked, and it asks for confirmation.

Cinema Player

Fernsteuerung Remote control

Rückseite · Erweiterte Funktionen Back · Further steps

  1. Token. Das Feld verschwindet, sobald die Verbindung steht. Token. The field hides once the phone is connected.

  2. Offline. Reißt die Verbindung ab, wird die Seite grau und zeigt Offline, bis sie wieder da ist. Offline. If the link drops, the page turns grey and shows Offline until it returns.

  3. Licht. Die Szenentasten sitzen unten und folgen der Lichtsteuerung am Pult. Lights. The scene buttons sit at the bottom and follow the booth light control.

  4. Lautstärke. Speichern schreibt den Pegel in den Playlist-Eintrag. Bei einem Standbild ist der Block ausgeblendet. Volume. Save writes the level into the playlist entry. On a still, that block is hidden.

  5. Lautstärke einstellen. Startet nur am Pult, der Status wird lila. Danach lassen sich Balken und Hüllkurve auch am Telefon ziehen. Pause und Still fragen dann nicht. Set volume. Started only at the booth; the status turns purple. The bar and envelope can then be dragged on the phone. Pause and Still no longer ask.

  6. Port und Token. Stehen im Fenster der Fernsteuerung, falls der QR-Code nicht reicht. Port and token. They are in the remote window, if the QR code is not enough.
